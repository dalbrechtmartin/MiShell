void parse_command ( char * line,
ParsedCommand * result )

Parses a command line into a ParsedCommand structure. Splits only on "&&"; pipes are kept inside commands.

Parses an input line into up to MAX_CMDS commands. Splits only on the logical operator "&&"; leaves pipes intact to be handled downstream. Background execution is detected via a trailing '&'.

Parameters
lineThe command line input.
resultPointer to a ParsedCommand structure to store the parsed result.
